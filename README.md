# ТЭЦ Симулятор — каркас

Браузерная игра без сборки: `index.html + style.css + app.js`.

## Запуск локально
Открой `tec-sim/index.html` в браузере. Тик — 1 сек.

## Что уже есть
- 2 котла: мощность, температура, давление, вода, охлаждение, вентиль тепла
- Спрос/выработка МВт, тепло в домах %, время смены 10 мин
- Экран 1 (главный котел) + Экран 2 (полное управление)
- 4 задания-события, журнал, авария при перегреве, победа при выживании

## Хостинг на GitHub Pages
1. Создай репозиторий, залей папку `tec-sim`
2. Settings → Pages → Deploy from branch → `main` / root (или `/tec-sim`)
3. Ссылка вида `ник.github.io/репо` — ее кидаешь друзьям
